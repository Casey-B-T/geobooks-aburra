      Sobre el proyecto

      Geobooks Aburrá es un geoportal académico. Los lectores de un mismo libro marcan su ubicación, el sistema calcula el centro geográfico del grupo y sugiere la biblioteca más cercana a ese centro para reunirse. Todos los datos llegan desde una API (FastAPI) conectada a PostgreSQL + PostGIS.

      Preguntas frecuentes

      ¿Cómo se calcula la biblioteca sugerida?

      Se pasan los puntos al sistema de coordenadas nacional (EPSG:9377, en metros), se calcula su centroide y se busca la biblioteca con menor distancia a ese centro.

      ¿Por qué el mapa usa EPSG:4326?

      Porque Leaflet trabaja con latitud y longitud. La base guarda la geometría en varios sistemas y la API convierte con ST_Transform.

      ¿Cómo creo un evento de lectura?

      Elige una biblioteca en el mapa o en las tarjetas, pulsa «Crear evento», selecciona el libro y la fecha.

      ¿Puedo ver las coordenadas de una biblioteca en otros sistemas?

      Sí. En el globo de cada biblioteca, el botón «Coordenadas» muestra la misma posición en 4326, 3857, 9377 y 3116.
